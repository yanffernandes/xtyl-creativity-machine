# Implementation Plan: Admin Model Visibility Configuration

**Branch**: `018-admin-model-visibility` | **Date**: 2025-12-03 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/018-admin-model-visibility/spec.md`

## Summary

Implementar configuração separada de modelos visíveis para texto e imagem no painel admin, exibir preços dos modelos, armazenar a lista localmente para eliminar requests ao OpenRouter na interface do usuário, e remover a seção "Modelos Recomendados" das configurações do workspace.

**Technical Approach**: Utilizar a infraestrutura existente do `system_config` com duas novas chaves (`visible_text_models` e `visible_image_models`), modificar os endpoints `/chat/models` e `/image-generation/models` para ler do banco ao invés do OpenRouter.

## Technical Context

**Language/Version**: Python 3.11 (Backend), TypeScript 5.x (Frontend)
**Primary Dependencies**: FastAPI, SQLAlchemy, Next.js 14, React 18, Shadcn/UI
**Storage**: Supabase PostgreSQL (existing system_config table)
**Testing**: pytest (Backend), Vitest (Frontend)
**Target Platform**: Web application (Docker-based deployment)
**Project Type**: Web (frontend + backend)
**Performance Goals**: Reduzir tempo de carregamento do seletor de ~500ms para <50ms
**Constraints**: Manter compatibilidade com configuração existente de `visible_models`
**Scale/Scope**: ~9 arquivos modificados, ~300 linhas de código
