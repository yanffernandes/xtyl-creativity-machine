## ⚡ 5-Minute Overview

### What is this feature?
**Arrow Articles** = Conversion-optimized blog articles with AI generation and WordPress publishing.

### What makes it different?
- ✅ Built-in CTAs (call-to-action elements)
- ✅ SEO-optimized with keyword targeting
- ✅ 5 conversion templates (Listicle, How-To, Review, Comparison, Guide)
- ✅ AI content generation (GPT-4)
- ✅ One-click WordPress publish

### Tech Stack
```
Frontend:  React 18 + TanStack Query + Zod
Backend:   NestJS + OpenAI API + WordPress API
Database:  Supabase (PostgreSQL + RLS)
```

### Architecture Pattern
```
Simple CRUD → Frontend ⟶ Supabase (RLS)
Complex Ops → Frontend ⟶ Backend ⟶ External APIs
```

## 📊 Database Schema (Quick Reference)

```sql
-- Main table
arrow_articles (
  id uuid PRIMARY KEY,
  user_id uuid REFERENCES auth.users,
  project_id bigint REFERENCES projects,
  title text NOT NULL,
  content text,
  meta_description text NOT NULL,
  primary_keyword text NOT NULL,
  secondary_keywords text[],
  cta_config jsonb NOT NULL,
  template_type text NOT NULL,
  status text DEFAULT 'draft',
  wpPost_id bigint,
  created_at timestamptz DEFAULT now()
)

-- RLS Policy
CREATE POLICY "Users can view own arrow articles"
  ON arrow_articles FOR SELECT
  USING (user_id = auth.uid());
```

## 🔑 Key API Endpoints

```typescript
// Frontend → Supabase (Direct)
GET    /arrow_articles           // List articles
GET    /arrow_articles/:id       // Get single article
POST   /arrow_articles           // Create article
PUT    /arrow_articles/:id       // Update article
DELETE /arrow_articles/:id       // Soft delete

// Frontend → Backend → External APIs
POST   /api/arrow-articles/:id/generate  // Generate content (OpenAI)
POST   /api/arrow-articles/:id/publish   // Publish to WordPress
GET    /api/arrow-articles/:id/metrics   // Get performance metrics
```

## 🐛 Common Issues & Solutions

### Issue: RLS Policy Blocks Insert
**Solution**: Ensure `user_id` matches `auth.uid()` in insert payload

### Issue: OpenAI API Rate Limit
**Solution**: Implement exponential backoff retry

### Issue: WordPress 401 Unauthorized
**Solution**: Verify WordPress app password is correct, check user permissions

### Issue: Content Generation Timeout
**Solution**: Increase backend timeout to 120 seconds, add progress updates

### Issue: Modal Not Closing After Submit
**Solution**: Reset form state and step counter on success

## 💡 Pro Tips

1. **Test RLS Early**: Create 2 test users and verify they can't see each other's articles
2. **Mock OpenAI in Tests**: Use fixtures to avoid API costs during testing
3. **Cache Projects Query**: Reuse projects dropdown data across modals
4. **Debounce Search**: Add 300ms debounce on search input
5. **Optimistic Updates**: Use TanStack Query's `onMutate` for instant UI feedback
6. **Error Boundaries**: Wrap modal components to prevent full page crashes
7. **Keyboard Shortcuts**: Add Cmd+K for quick create on list page
